# ⚡ Roblox Image Fix

**Быстрый фикс загрузки картинок в Roblox** (аватары, одежда, иконки, превью игр и другой CDN-контент).

Особенно актуально для пользователей из России, где изображения часто перестают загружаться из-за проблем с DNS / CDN.

---

## Возможности

- Одна кнопка — и картинки снова грузятся
- Поддержка DNS-серверов:
  - **Geohide** (основной, рекомендуется)
  - Geohide Win11 / Geohide 1
  - Cloudflare
  - Google
  - Quad9
  - Свой DNS
- Автоматическая настройка **DNS over HTTPS (DoH)** на Windows 11
- Работает со всеми сетевыми адаптерами
- Резервное копирование и восстановление оригинальных DNS (DHCP)
- Современный Glass UI
- Автозапуск (опционально)
- Установщик с проверкой и скачиванием .NET Desktop Runtime

## Как пользоваться

1. Скачай последнюю версию из [Releases](https://github.com/wast3r1/RobloxImageFix/releases)
2. Запусти **от имени администратора**
3. Нажми кнопку **FIX IMAGES**
4. Перезайди в Roblox

Готово — картинки должны начать загружаться.

---

## Системные требования

- Windows 10 / 11 (x64)
- .NET Desktop Runtime 10 (установщик скачает автоматически, если его нет)
- Права администратора (нужны для изменения DNS)
